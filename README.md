بومی‌سازی حرفه‌ای و کامل وردپرس برای فارسی‌زبانان.

== Description ==

افزونه فردوسی نسخه ۲.۰ یک بسته جامع بومی‌سازی است که شامل:

* تاریخ شمسی کامل
* فونت وزیرمتن محلی (با نسخه Farsi Digits)
* ارقام و حروف فارسی
* یکپارچگی عمیق ووکامرس (تاریخ سفارش، ایمیل، موبایل، کد ملی)
* پیوند یکتای شمسی
* پشتیبانی ACF
* ویجت تقویم و داشبورد
* شورت‌کدهای متعدد
* بهبود جستجو، ایمیل‌ها، گوتنبرگ
* خروجی/ورودی تنظیمات
* همراه با قالب راست‌چین فارسی
